2. Hướng dẫn cài đặt environment
- Mở Terminal tại thư mục gốc của dự án và chạy câu lệnh sau để cài đặt các gói phụ thuộc:
**pip install -r requirements.txt**

3. Hướng dẫn chạy chương trình
- Sau khi cài đặt xong thư viện, khởi động Backend bằng lệnh:
**uvicorn backend.main:app --reload**
- Khởi động Frontend (giao diện) bằng lệnh:
**streamlit run frontend/app.py**
